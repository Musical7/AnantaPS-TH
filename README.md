# Ananta - Server & Client Launcher

ระบบ Launcher และเซิร์ฟเวอร์จำลองสำหรับโปรเจกต์ Ananta

![Ananta Preview](./image.png)

## คุณสมบัติหลัก

- **AnantaDEV.exe:** GUI Launcher สำหรับจัดการการเริ่มและหยุดเซิร์ฟเวอร์ รวมถึงเครื่องมือที่เกี่ยวข้อง
- **Web Console / API:** ใช้ตรวจสอบสถานะและจัดการเซิร์ฟเวอร์ในเครื่องผ่าน [http://127.0.0.1:17888/](http://127.0.0.1:17888/)
- **Drmk.Server:** เซิร์ฟเวอร์หลักสำหรับจัดการข้อมูลและคำขอ
- **Drmk.Proxy:** พร็อกซีสำหรับจัดการการเชื่อมต่อเครือข่าย
- **Drmk.SDK:** ไลบรารีและโครงสร้างข้อมูลสำหรับส่วนประกอบของโปรเจกต์

## ข้อกำหนดและเครื่องมือ (Prerequisites)

เอกสารนี้อธิบายการใช้งานบน Windows เครื่องมือสำหรับพัฒนาและสร้างส่วนประกอบอาจแตกต่างกันตามส่วนของโปรเจกต์ที่ต้องการใช้งาน:

- **.NET 8.0 SDK:** สำหรับสร้างหรือพัฒนาส่วนประกอบที่ใช้ .NET
- **Rust (64-bit):** สำหรับส่วนประกอบที่พัฒนาด้วย Rust
- **Python:** สำหรับสคริปต์และเครื่องมือที่เกี่ยวข้อง
- **Node.js:** สำหรับเครื่องมือหรือส่วนติดต่อเว็บที่ใช้ Node.js
- **Visual Studio Build Tools:** เลือก workload **Desktop development with C++** เมื่อต้องสร้างส่วนประกอบภาษา C++ หรือ Rust ที่ต้องใช้ตัวเชื่อมโยง C++
- **Visual Studio Code:** โปรแกรมแก้ไขโค้ดที่แนะนำ

การใช้งาน Launcher ที่สร้างไว้แล้วอาจไม่จำเป็นต้องติดตั้งเครื่องมือสำหรับพัฒนาทั้งหมด ให้ตรวจสอบข้อกำหนดของส่วนประกอบที่ต้องการใช้งานก่อนติดตั้ง

ดาวน์โหลดเครื่องมือจากเว็บไซต์ทางการ:

- [Visual Studio Code](https://code.visualstudio.com/)
- [Rust](https://www.rust-lang.org/tools/install)
- [Python สำหรับ Windows](https://www.python.org/downloads/windows/)
- [.NET 8.0](https://dotnet.microsoft.com/en-us/download/dotnet/8.0)
- [Node.js](https://nodejs.org/)
- [Visual Studio](https://visualstudio.microsoft.com/downloads/)

## วิธีใช้งานทั่วไป

1. เตรียม Launcher และส่วนประกอบของเซิร์ฟเวอร์ตามข้อกำหนดของโปรเจกต์
2. เปิด **`AnantaDEV.exe`**
3. หาก Launcher ต้องใช้ไคลเอนต์ ให้ตั้งค่า **Game Path** ไปยังไคลเอนต์ที่ติดตั้งและได้รับอนุญาตให้ใช้งานบนเครื่องของคุณ
4. กด **Start server** เพื่อเริ่มเซิร์ฟเวอร์
5. ตรวจสอบสถานะผ่าน [http://127.0.0.1:17888/](http://127.0.0.1:17888/)
6. เมื่อเซิร์ฟเวอร์พร้อมแล้ว ใช้ **Launch game** ใน Launcher หากต้องการเปิดไคลเอนต์
7. เมื่อใช้งานเสร็จ ให้หยุดเซิร์ฟเวอร์จาก Launcher ก่อนปิดโปรแกรม

## การตั้งค่าใน Launcher

- **Install certificate:** จัดการใบรับรองที่ Launcher ใช้
- **Install fast-start patch:** เปิดใช้ตัวเลือกเริ่มต้นเซิร์ฟเวอร์แบบรวดเร็ว หากรองรับ
- **Traffic / Crowd / Destructible:** เปิดหรือปิดองค์ประกอบที่เกี่ยวข้องในเซิร์ฟเวอร์
- **Show console window:** แสดงหน้าต่างคอนโซลเพื่อดูข้อความสถานะและช่วยตรวจสอบปัญหา

หากพบปัญหา ให้ตรวจสอบสถานะใน Launcher และข้อความในคอนโซลก่อน จากนั้นตรวจสอบว่าเซิร์ฟเวอร์เริ่มทำงานแล้วและเปิด Web Console จากเครื่องเดียวกัน
